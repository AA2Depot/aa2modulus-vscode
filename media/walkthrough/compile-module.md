# Compile it

Save the module as a `.aa2m` file, then run **AA2M: Compile Module** or use the
build button in the editor title. Pick an output path without an extension;
AAUnlimited module files have none.

Unsaved changes are compiled too; nothing is saved for you. Errors appear in
the editor and the Problems panel, and the full report goes to
**AA2M: Show Language Server Output**.

To go the other way, run **AA2M: Decompile Module** on an existing binary module
to open it as editable source.
